# ARVEN — Elementor Template Kit Prototype

Static HTML prototype for the first TFT commercial template concept.

## Positioning
Financial Advisory & Fractional CFO Elementor Template Kit.

## Files
- `index.html` — homepage prototype
- `styles.css` — responsive styles
- `script.js` — mobile navigation
- `ELEMENTOR-BUILD-GUIDE.md` — implementation mapping

## Deployment
This repository is intentionally build-free so it can be connected directly to Cloudflare Pages.

Suggested Cloudflare Pages settings:
- Production branch: `main`
- Framework preset: None
- Build command: leave empty
- Build output directory: `/`
