# ARVEN — Fractional CFO Elementor Template Kit Prototype

ARVEN is a commercial-design prototype for a Fractional CFO, strategic finance and financial advisory Elementor Template Kit. The homepage is designed around founder-led growth companies that need senior finance support across cash flow, forecasting, FP&A, fundraising and board reporting.

## Homepage content architecture
1. Hero — positioning and primary advisory CTA
2. Finance, With Direction — core value proposition
3. Growth Gets Expensive — business problem + proof metrics
4. What Founders Say — testimonial carousel
5. Services — Fractional CFO, Cash Flow & Runway, Forecasting & FP&A, Fundraising & Board
6. Selected Work — growth-stage case study and finance outcomes
7. Brand statement — decision-led finance positioning
8. How It Works — Diagnose, Build, Partner, Evolve
9. Perspective — founder/advisor point of view
10. The Finance Brief — educational finance insights
11. Contact CTA + footer

## Design system
- Display: Anton
- Body: Manrope
- Utility/meta: DM Mono
- Palette: dark green, warm cream, signal orange, warm paper
- UI language: oversized editorial typography, rounded cards/images, strong whitespace, controlled sticker accents, sequential entrance motion
- Responsive targets: desktop, tablet and mobile
- Accessibility: visible focus states, reduced-motion support, semantic source markup and descriptive image alt text

## Files
- `index.html` — semantic homepage source/fallback
- `styles.css` — base responsive styles
- `script.js` — prototype composition, interactions and reveal behavior
- `hero-v2.css` / `hero-v2-fix.css` — approved hero treatment
- `section2.css`, `section3.css`, `section4.css` — approved section treatments
- `sections5-footer.css` — remaining homepage section system
- `themeforest-final.css` — final commercial-kit consistency and accessibility overrides
- `ELEMENTOR-BUILD-GUIDE.md` — Elementor implementation mapping

## Deployment
The prototype is intentionally build-free and can be connected directly to Cloudflare Pages.

Suggested settings:
- Production branch: `main`
- Framework preset: None
- Build command: leave empty
- Build output directory: `/`

## Commercial prototype notes
- Company names, testimonials, case studies, people, email addresses and performance metrics are fictional demo content and must be replaced by the buyer.
- Remote photography is used only for prototype presentation; production/template distribution should use properly licensed or buyer-provided imagery according to marketplace requirements.
- The HTML prototype is the visual source of truth before final Elementor conversion and packaging.
